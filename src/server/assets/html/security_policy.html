Reporting a vulnerability

If that is unavailable, email {{.Data.email}}.

Please include the affected version, a description of the issue and its impact, and steps to reproduce it. Do not publish vulnerability details before coordinating with the maintainers.

Response process

  • Receipt is acknowledged within 48 hours.
  • Critical vulnerabilities are targeted for a fix within 14 days.
  • The disclosure timeline is coordinated after a fix is available.

Only the latest release receives security updates. See the security overview for reporting links.
