About GitIgnore

GitIgnore is a full-stack Go web application for serving .gitignore templates. It provides a curated library of templates for languages, frameworks, editors, and tools through a versioned REST API, a GraphQL endpoint, and a server-side rendered web UI with a browser and composer.

What it does

  • Curated .gitignore templates for languages, editors, frameworks, and OS patterns.
  • Single template retrieval by name (case-insensitive).
  • Template composition — merge multiple templates into one output.
  • A companion CLI, gitignore-cli, for shell-pipeline use.
  • A drop-in compatible replacement for the gitignore.io / Toptal gitignore API.

Templates are embedded in the binary at build time, so the service deploys as a single self-contained static binary with no external dependencies at runtime.

This service stores and serves no personal data. All endpoints are public and require no authentication.

Source and issues: github.com/apimgr/gitignore.
