Overview

GitIgnore provides a curated library of templates for languages, frameworks, editors, and tools through a versioned REST API, a GraphQL endpoint, and a server-rendered web interface.

  • Curated .gitignore templates for languages, editors, frameworks, and OS patterns.
  • Single template retrieval by name (case-insensitive).
  • Template composition — merge multiple templates into one output.
  • A companion CLI, gitignore-cli, for shell-pipeline use.
  • A drop-in compatible replacement for the gitignore.io / Toptal gitignore API.
  • Browse templates by category, search by name, and view template statistics.
  • OpenAPI and GraphQL documentation for API clients.

Templates are embedded in the binary at build time, so no separate template service is needed. Optional GeoIP support downloads its database files and refreshes them through the scheduler.

Data handling

GitIgnore has no user registration or profile pages. Owners are anonymous identities represented by owner tokens; operator actions require an operator token. Catalog endpoints are public. Contact and security reports may include the identity, contact details, and report information their sender submits. Request metadata may be processed for abuse prevention, rate limiting, and optional GeoIP lookup; instance operators control their own access logs.
