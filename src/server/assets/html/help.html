Help

GitIgnore serves .gitignore templates over the web, a REST API, and a CLI.

In the browser

  • Search — find a template by name or keyword.
  • All Templates — browse every available template.
  • Categories — browse by language, editor, framework, or OS.
  • Combine — merge several templates into one file.

From the command line

curl {{.BaseURL}}/api/v1/templates/go
curl "{{.BaseURL}}/api/v1/combine?templates=go,node,macos" > .gitignore

The gitignore-cli client wraps these calls for shell pipelines:

gitignore-cli Go Node > .gitignore

API documentation

Full API reference is available at API Docs, with interactive Swagger at /server/docs/swagger and GraphQL at /server/docs/graphql.
