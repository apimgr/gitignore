What this is

This application exposes its API operations as tools over remote Streamable HTTP. Each request uses the same Bearer token and authorization rules as the REST API.

Select the URL to copy it. The endpoint accepts JSON-RPC requests with HTTP POST.

Authentication

MCP requires Authorization: Bearer <token>. The REST catalog remains public, but MCP requests without a valid token receive 401. Use a linked owner token for each MCP client; create and manage it at Token Management. Do not give an MCP client the primary owner token or the operator token.

Connect a client

Configure your MCP client to use the endpoint above with Streamable HTTP transport. For a direct protocol check:

curl -X POST '{{.Data.url}}' -H 'Authorization: Bearer YOUR_LINKED_TOKEN' -H 'Content-Type: application/json' -H 'Accept: application/json, text/event-stream' -H 'MCP-Protocol-Version: 2026-07-28' -H 'Mcp-Method: initialize' -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2026-07-28","capabilities":{},"clientInfo":{"name":"curl","version":"1.0"}},"_meta":{"io.modelcontextprotocol/protocolVersion":"2026-07-28"}}'

Behavior and limits

The endpoint is stateless, accepts POST only, applies the same request middleware and rate limits as the API, and validates browser Origin headers.

Troubleshooting

Troubleshooting responses
StatusCauseResolution
400Malformed JSON-RPC request, invalid headers, or unsupported protocol versionSend valid JSON-RPC with matching MCP headers and protocol version 2026-07-28.
401Missing or invalid Bearer tokenCreate a linked token at /server/preferences/tokens and send it in the Authorization header.
403Origin rejectedSend requests from this site's own origin.
405Method is not POSTSend the JSON-RPC request using POST.
